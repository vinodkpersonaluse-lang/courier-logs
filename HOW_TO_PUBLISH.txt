SAMPLE COURIER LOG - free installable app (PWA)

Your data stays only on the phone. No server, no login, no ads, no cost.

PUBLISH FREE (one time, 10 minutes, ask any helper):
1. Create a free account at github.com
2. New repository -> name: courier-log -> Public -> Create
3. "uploading an existing file" -> upload ALL the files from this zip -> Commit
4. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder / (root) -> Save
5. After 1-2 minutes your link is: https://YOURNAME.github.io/courier-log/

INSTALL ON PHONE:
Open that link in Chrome -> menu (3 dots) -> Install app / Add to Home screen.

KEEP SAFE: Backup tab -> Download Excel file every week.
